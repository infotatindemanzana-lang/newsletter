# Imágenes de las newsletters de Tatín de Manzana

Una carpeta por newsletter (`AAAA-MM-tema/`). Se publican con GitHub Pages en
`https://infotatindemanzana-lang.github.io/newsletter/AAAA-MM-tema/archivo.jpg`
y los emails de Brevo las cargan desde ahí. No borrar ni renombrar archivos de
newsletters ya enviadas: los correos dejarían de mostrar las imágenes.
